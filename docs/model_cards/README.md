# Model Cards

This directory holds the model cards for the registered models:

| File | Model |
|---|---|
| [demand.md](demand.md) | `taxi-demand-forecaster` (XGBoost) |
| [fare.md](fare.md) | `taxi-fare-predictor` (LightGBM) |

Each card records the intended use, training data period, validation and test
metrics, subgroup error results and known limitations.

The cards are generated by the responsible AI analysis, which also writes the
fairness JSON and SHAP plots under `artifacts/responsible/`:

```bash
.venv/bin/python -m scripts.responsible.run_analysis
```

Add `--problem fare` or `--problem demand` to regenerate one card. The dashboard
image copies this directory, so the cards shown on the dashboard always match
the committed versions.
