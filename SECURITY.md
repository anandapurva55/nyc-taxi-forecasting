# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub. Open the **Security** tab of this repository and choose **Report a vulnerability**, or use [the report form](https://github.com/anandapurva55/nyc-taxi-forecasting/security/advisories/new).

Include what you found, the steps to reproduce it and what an attacker could gain. You can expect a reply within seven days, and a confirmed problem is fixed before it is discussed in public.
